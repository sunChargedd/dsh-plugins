# DSH Plugins market index

A self-hosted [format-1](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) plugin market index for both plugins.

Users can add this URL in **DSH → Settings → Plugins → Discover → Index sources**:

```text
https://raw.githubusercontent.com/sunChargedd/dsh-plugins/main/market/index.json
```

It contains:

- `dsh-mcp-skill-manage@0.5.5` — skill and MCP manager (npm source)
- `dsh-ssh-manage@0.2.1` — SSH host manager with a persistent PTY terminal (npm source)

Update the versions here whenever a new npm release is published. The `awesome/` directory holds the submission files for the official awesome-dsh-plugin list.
